# Product video and motion graphics

Video is an optional deliverable, not a mandatory detour for website work. Define format, duration, fps, aspect ratio, platform, audio requirements and content rights. Distinguish real-product capture, template adaptation and original storyboard creation. Choose with the user only when it changes the deliverable; do not repeatedly reopen a delegated direction.

Build a storyboard with purpose per shot: context, interaction, benefit, transition and payoff. Use the actual product screenshots and states; never fabricate product behavior. Keep type legible at delivery resolution. Establish safe margins, continuity, shot duration and sound/beat relationship. A recipe is a vocabulary, not a rigid house style.

Remotion compositions must be frame-driven and reproducible. Use the current supported API and deterministic interpolation/springs/sequences; browser CSS/RAF timing is not a deterministic render timeline. Validate start/end frames, duration, frame ranges, repeated renders, asset availability, fonts, audio synchronization and aspect-ratio variants.

Inspect contact sheets and full playback; verify no blank frames, accidental cuts, missing assets, text clipping, flicker, unreadable motion or truncated audio. Preserve editable source and output metadata. Video Shotcraft's licensed text is included as source reference in its original language; our workflow is English. Remotion upstream skill files remain link-only until redistribution terms are established; use [official Remotion documentation](https://www.remotion.dev/docs/animating-properties) for implementation.
