# Style selection

The full extracted UI/UX Pro Max style database is bundled under references/upstream/ui-ux-pro-max/. Search the data instead of loading all rows. Status, suitability, accessibility and performance constraints matter; an archived/replacement row is not automatically the right current choice.

The prepared snapshot has 88 database rows, including 50 marked active. assets/style-catalog.json preserves the full rows and the source path, plus our Quiet Luxury / Couture preset. Offer a small relevant shortlist, with an option to explore the wider catalog.

These are our routing presets, not replacements for upstream style variety. Support a custom direction and combinations with one dominant grammar. Search palettes, typography, UX and stack guidance separately after the direction is selected. For THE MODA-inspired luxury, request actual references only when an exact brand match is required; otherwise use the stated premium ambition and identify it as an interpretation.
